What this manager controls
  • Local skill metadata for Codex, Qwen Code, and Claude Code. It does not configure hosted ChatGPT or claude.ai accounts.
  • Plugin tools, hooks, and injected instructions have separate controls. Their presence is shown below each affected group.
  • New files and updates are reconciled every 15 seconds after a short settling period. Open tasks may retain already-loaded instructions; start a fresh task after changing a policy.
  • Cached copies share one choice across versions. A cached plugin is not necessarily enabled by its host.
  • Only registered project folders are scanned. Register each relevant nested project separately.
